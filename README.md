# afad-toplanma-alani-haritasi
AFAD anında kullanıcıya en yakın toplanma alanını harita üzerinde gösteren web tabanlı staj projesi.

Giriş için:
$env:SmtpSettings__SenderEmail="your-gmail-address@gmail.com",
$env:SmtpSettings__AppPassword="your-16-character-app-password" bu commandler kendi mailiniz için değiştirilerek terminalde atanacaktır backend çalıştırlmadan önce.
